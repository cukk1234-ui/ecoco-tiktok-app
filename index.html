Ecoco 台灣團隊

Ecoco 本機短影音發布器

一套給 Ecoco 台灣內部營運人員使用的桌面工具，用來管理自有繁體商品短影音、檢查成效，並透過 TikTok 官方 API 發布至 Ecoco 官方 TikTok 帳號。

這個 App 做什麼

Ecoco 本機短影音發布器不是登入頁，也不是一般行銷 landing page。它是 Ecoco 台灣團隊正在使用的內部營運工具公開說明頁，讓 TikTok 審核人員了解 App 的產品目的、授權流程、資料使用方式與測試內容。

  • 整理 Ecoco 自有商品影片與已核准文案。
  • 讓授權管理者確認標題、隱私設定、互動設定與商業內容揭露。
  • 使用 TikTok Content Posting API 上傳並發布自有影片。
  • 使用 TikTok 官方 API 讀取帳號基本資訊、粉絲統計與影片列表，用於每日社群成效回報。

服務區域

本 App 僅供 Ecoco Taiwan 團隊在台灣營運官方 TikTok 帳號使用，內容為繁體中文商品教育短影音。Ecoco 不在中國大陸地區提供此 TikTok App，也不要求中國大陸 IP 位址存取或測試本服務。

運作方式

  1. 授權管理者透過 TikTok Login Kit 登入。
  2. App 以 OAuth 2.0、PKCE 與 state 驗證完成授權，不要求或保存 TikTok 密碼。
  3. 工具查詢帳號可用的發布、隱私、互動與創作者設定。
  4. 管理者選擇 Ecoco 自有影片並確認標題、揭露與發布設定。
  5. 工具以 TikTok Content Posting API 上傳、發布，並查詢發布結果。
  6. 每日報表只讀取官方 API 提供的粉絲、影片清單與可見成效資料；平台未提供時會標示為未提供，不推測。

要求的 TikTok 權限

權限 用途
user.info.basic確認授權帳號與顯示名稱。
user.info.stats讀取粉絲與公開統計，供每日社群報表使用。
video.list核對官方帳號已公開影片清單與可見成效。
video.upload上傳 Ecoco 已審核的自有短影音檔案。
video.publish在管理者確認後發布至 Ecoco 官方 TikTok 帳號。

資料安全

授權 Token 只保存在管理者 Mac 的 macOS Keychain。本工具不讀取瀏覽器 Cookie、不保存 TikTok 密碼，也不繞過平台安全驗證。
