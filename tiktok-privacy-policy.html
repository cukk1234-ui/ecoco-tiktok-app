本機短影音發布器隱私政策

最後更新：2026-07-21

本政策說明「Ecoco 本機短影音發布器」如何處理經 TikTok 使用者明確授權的資料。本工具僅供 Ecoco 台灣團隊管理自有 TikTok 帳號與自有繁體商品影片使用。

處理的資料

  • TikTok Login Kit 回傳的帳號識別碼、顯示名稱、頭像與授權範圍。
  • Access token、refresh token、Token 到期時間與授權狀態。
  • 由管理者選擇的影片、貼文標題、隱私與互動設定、商業內容揭露選項。
  • 發布工作識別碼、處理狀態、錯誤碼與時間戳記。

使用目的

資料只用於驗證 Ecoco 授權管理者、顯示 TikTok 帳號可用的發布選項、上傳自有影片、查詢發布結果、防止重複發布與內部營運稽核。本工具不出售資料、不建立與 Ecoco 社群營運無關的個人輪廓，也不代表第三方帳號發布內容。

儲存與安全

授權 Token 儲存在管理者 Mac 的 macOS Keychain；發布佇列與必要的稽核紀錄保存在本機。工具使用 OAuth 2.0、PKCE 與 state 驗證防止請求偽造，不讀取瀏覽器 Cookie、不保存 TikTok 密碼、不繞過登入或 CAPTCHA。

資料分享與保存期限

除向 TikTok 官方 API 傳送管理者確認的資料、依法令要求或維護安全所必要外，我們不向第三方揭露資料。本機發布紀錄僅保存至營運與稽核不再需要時；授權 Token 在撤銷授權或刪除要求完成後移除。

控制、撤銷與刪除

授權管理者可隨時停止使用工具、在 TikTok 撤銷 App 授權，或要求刪除本機保存的 TikTok 授權與發布紀錄。撤銷後，本工具不再代表該帳號呼叫 TikTok API。

聯絡方式

如需查詢、撤銷授權或刪除資料，請透過 Ecoco 官方社群帳號或 Ecoco 官方賣場客服聯絡管理者。
