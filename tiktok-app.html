TikTok review details for a creator-controlled publishing workflow.

This page is written for TikTok App Review. It explains what Ecoco Creator Studio does, who uses it, why each scope is requested, how content is reviewed before publishing, and how data is protected.

Product purpose

Prepare, publish and verify Ecoco product education videos.

Ecoco Creator Studio supports authorized creators who publish Ecoco-owned or Ecoco-licensed product education videos. The product organizes approved video assets, displays TikTok account context, lets the creator confirm metadata and posting settings, uploads approved content through TikTok Content Posting API when the app has permission, and records available posting evidence for daily reporting.

The platform is designed for Taiwan-based Traditional Chinese content operations. It is not offered in mainland China and does not require mainland China IP access for review or production use.

End-to-end creator flow

  1. Sign in: The creator uses TikTok Login Kit. The app validates OAuth state and PKCE before accepting the callback.
  2. Confirm account: The app shows the authorized account identity so the creator knows which TikTok account will be used.
  3. Select content: The creator selects an Ecoco-owned vertical video from the approved queue.
  4. Review metadata: The creator confirms title, caption, hashtags, privacy level, interaction settings and commercial-content disclosure.
  5. Publish or hand off: If Content Posting API permission is available, the app sends the approved request through TikTok official APIs. If approval is unavailable, the app prepares a native upload package and does not mark it published.
  6. Verify: The app records TikTok API response IDs, public URLs or unavailable-data reasons. It never reports missing data as zero.

Safety and compliance boundaries

  • No TikTok password collection.
  • No browser cookie or session scraping.
  • No CAPTCHA, login, warning or review bypass.
  • No hidden bulk publishing: the creator reviews content and settings before publishing.
  • No false publication claims: without an API response, public URL, video ID or visible platform evidence, the job is not marked published.
  • No resale of TikTok user data or unrelated user profiling.

Current Content Posting API limitation

Until TikTok approves the app for public Content Posting API use, Ecoco Creator Studio keeps affected TikTok jobs in a blocked or handoff-ready state. In that state, the app creates a native upload package for TikTok Studio / TikTok app review, but it does not claim that the video has been publicly posted through the API.

This limitation is intentionally visible in the product and reporting workflow because publication status must be evidence-based.

Reviewer testing checklist

  1. Open the public website, Terms and Privacy pages from a TikTok-supported region.
  2. Confirm this is a product description and review hub, not a login-only page.
  3. Review the requested scope table and the end-to-end creator flow.
  4. Watch the representative video asset.
  5. Use TikTok Login Kit in the review environment with a reviewer or authorized test account.
  6. Confirm that the creator is shown the account and posting settings before content is sent.
  7. Confirm that unavailable publication or metric evidence is labelled unavailable instead of guessed.
