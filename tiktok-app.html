Ecoco 台灣團隊

App 說明與 TikTok 審核資訊

最後更新：2026-08-02

Ecoco 本機短影音發布器協助 Ecoco 台灣團隊以人工審核、本機保存與官方 API 的方式，管理 TikTok 短影音發布與每日成效回報。

產品背景

Ecoco 台灣營運多個居家收納與生活用品社群帳號。這個 App 用於官方 TikTok 帳號的內部工作流程：把已製作、已授權、已確認的繁體中文商品教育短影音，透過 TikTok Content Posting API 發布，並用 TikTok 官方 API 回讀可見成效資料。

主要使用者

  • Ecoco 台灣社群營運人員。
  • 已被授權管理 Ecoco 官方 TikTok 帳號的人員。
  • TikTok App Review 審核人員，可透過本頁了解 App 功能、授權範圍與資料使用方式。

主要功能

授權連線

使用 TikTok Login Kit、OAuth 2.0、PKCE 與 state 驗證連線官方帳號，Token 儲存在管理者本機 macOS Keychain。

影片發布

管理者選擇 Ecoco 自有影片，確認標題、隱私、互動與商業內容揭露後，App 透過 Content Posting API 上傳並發布。

成效回報

App 讀取 TikTok 官方 API 可提供的粉絲統計、已公開影片清單、觀看、按讚與留言等資料。若平台或權限未提供，報表會標示未提供。

安全稽核

App 保存本機工作紀錄以避免重複發布，並且不讀取 Cookie、不保存密碼、不繞過登入、CAPTCHA 或任何平台限制。

授權範圍與用途

Scope 使用原因
user.info.basic辨識授權帳號，確認目前連線的是 Ecoco 官方 TikTok 帳號。
user.info.stats取得粉絲與帳號統計，產生每日社群數據回報。
video.list確認當日影片是否實際公開，並讀取 TikTok 官方可見的影片成效。
video.upload上傳管理者選定的 Ecoco 自有短影音。
video.publish在人工確認後發布影片至 Ecoco 官方 TikTok 帳號。

測試流程

  1. 打開本頁與隱私政策、服務條款，確認這是完整公開說明而不是登入頁。
  2. 觀看下方示範影片，確認 App 處理的是 Ecoco 自有商品教育短影音。
  3. 在 TikTok 審核環境中使用 Login Kit 授權測試帳號或 Ecoco 授權帳號。
  4. 檢查 App 只會要求上方列出的必要 scope。
  5. 在 demo 中確認發布前有人工作業確認，不會自動大量發布或繞過平台審核。

資料處理承諾

  • 不出售或分享 TikTok 使用者資料給第三方行銷名單。
  • 不代表非 Ecoco 帳號發布內容。
  • 不收集 TikTok 密碼、Cookie 或瀏覽器工作階段。
  • 不以爬蟲或畫面擷取取代 TikTok 官方 API 權限。
  • 撤銷授權後，App 不再代表該 TikTok 帳號呼叫 API。

如需測試帳號、審核協助、資料刪除或安全問題，請透過 Ecoco 官方社群帳號或 Ecoco 官方賣場客服聯絡管理者。
